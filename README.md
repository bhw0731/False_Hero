# 스프라이트 폴더

이 폴더에 PNG 파일을 넣으면 게임이 자동으로 사각형 대신 스프라이트를 사용합니다.
파일이 없으면 그대로 사각형으로 동작 — 코드 수정 필요 없음.

## 기대하는 파일 (선택)

| 파일명 | 용도 | 권장 크기 |
|---|---|---|
| `player.png`  | 플레이어 캐릭터 | 64×64 (정사각) |
| `enemy.png`   | 일반 잡몹 | 48×48 |
| `subboss.png` | 서브보스 | 96×96 |
| `boss.png`    | 메인 보스 4종 공통 | 128×128 |

## 어디서 받나

## 색상 처리

- 보스 4종은 같은 `boss.png` 를 쓰고, 코드에서 `setTint()` 로 색을 바꿔 구별합니다 (암살자=빨강 / 거인=회색 / 광전사=주황 / 환영=보라).
- 플레이어도 클래스 선택 시 클래스 색상으로 tint 됩니다.
- 그래서 스프라이트는 단색·중립 톤(흰/회색)으로 만들면 색 변화가 잘 보임.

## 추가 후 확인

- `cd frontend && npm run dev` 재시작
- 브라우저 콘솔에 404 뜨던 게 사라지면 성공
